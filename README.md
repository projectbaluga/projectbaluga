# Wilson Villanueva — Portfolio

Personal portfolio site. Plain HTML / CSS / JavaScript, no build step.

**Live:** https://projectbaluga.github.io/portfolio/

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy (GitHub Pages)

Served by GitHub Pages from the `main` branch root:
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.

## Files

- `index.html` — page markup
- `styles.css` — styling, animations, scroll transitions
- `script.js` — carousel, lightbox, scroll reveals, theme toggle
- `assets/` — screenshots, avatar, favicons, social image
