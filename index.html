Case 01 — Main project · Full-stack platform

FairLink

ISP & Hotspot Management System

Private repo · walkthrough on request

A complete ISP & hotspot management system built on the MERN stack and Docker. It covers billing, subscriber CRM, MikroTik router control, hotspot vouchers, a coin-operated kiosk system, and an Android companion app for field work — all running together as one containerized platform.

  • 12Dashboard modules
1 / 9

Billing

Automatic monthly invoicing, pro-rated charges, partial payments, and PDF statements.

Dashboard & CRM

Subscriber management, financial summaries, and a live map of field technicians.

Hotspot & Vouchers

FreeRADIUS authentication, bulk voucher printing, and live session monitoring.

Router Control

Direct MikroTik API integration — enable, disable, and monitor subscribers from the dashboard.

Kiosk System

Coin-operated PC sessions with ESP8266 hardware, remote lock/unlock, and receipt printing.

Support & Inventory

Real-time ticket chat and barcode-based stock tracking.

Android App

Field app for technicians: GPS reporting, tickets, and subscriber lookup.

Security

JWT auth, role-based permissions, encryption at rest, and account lockout.

How it works

Architecture

Six Docker services working together — React frontend, Express API, MongoDB, FreeRADIUS, WireGuard VPN, and a socket proxy.

Real-time

WebSockets keep technician GPS, ticket chat, and kiosk sessions in sync across every device.

Automation

The daily billing cycle, overdue-subscriber syncing to routers, and kiosk time deductions all run on their own.

Networking

Talks to MikroTik routers over API, handles both PPPoE and IPoE connections, and manages hotspot sessions end to end.

Case 02 — Side project · Systems & security

SafePlay

Anti-Cheat Tool for Online Games

GitHub

A side project exploring how anti-cheat tools work. It's a Windows DLL for Ragnarok Online clients that serves a trusted configuration from memory, verifies game files, and checks for known cheat tools — paired with a launcher that makes sure the game starts clean. Written in C++.

Configuration

Keeps game server settings stored safely in the DLL so they can't be easily changed.

File Check

Verifies game files haven't been tampered with before allowing the game to start.

File Patching

Intercepts file access attempts to protect configuration from being modified.

Cheat Detection

Regularly checks for known cheat tools running in the background.

Protected Launch

Game only runs through a special launcher to ensure protections are in place.

Notifications

Shows the player what's blocking them if a cheat tool is detected.

(04) Process

How I build

  1. 01

    Understand

    Start with the actual problem — how subscribers pay, how routers behave, how people really work day to day.

  2. 02

    Prototype first

    Get a rough version running fast, with AI as a pair programmer. Cheap to throw away, quick to learn from.

  3. 03

    Build end to end

    Frontend, API, database, networking — even firmware when needed. One coherent system, not scattered pieces.

  4. 04

    Ship & iterate

    Dockerized deploys, tests where they matter most, then keep refining from real usage.
