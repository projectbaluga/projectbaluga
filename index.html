FairLink

Automated ISP & Hotspot Management System

View Source ↗

FairLink is a production-grade management platform for local ISPs, built to automate the entire lifecycle of a subscriber—from automated billing and MikroTik router enforcement to secure remote networking and AI-optimized diagnostics.

  • ~3sBilling Cycle (100+ users)
  • 1k+Est. Subs per Router
  • 6Docker Services
  • Real-timeMikroTik Sync

Challenge #1: High-Density Router Enforcement

Naive API calls per subscriber would overwhelm MikroTik CPU. The system needed to sync state for hundreds of users without lag or service interruption.

Solution: Implemented In-Memory Categorization and Persistent Connection Sharding. Commands are batched by router and state before execution, utilizing a single optimized API tunnel to reduce overhead by ~80%.

Challenge #2: Secure Remote Networking

RADIUS traffic needed to reach a containerized backend from remote field routers sitting behind restricted networks or CGNAT.

Solution: Built a WireGuard VPN Mesh with custom iptables DNAT rules. RADIUS packets are routed through secure tunnels directly to the FreeRADIUS container, ensuring zero-config connectivity for field hardware.

Challenge #3: Complex Billing & Idempotency

Handling overflow days (e.g., Feb 28th for Day 31 subs) and preventing double-billing during automated daily cycles was critical for financial integrity.

Solution: Developed an Idempotency Guard with last-billed markers and a Monthly Proration Formula. Added "Frozen Billing" for inactive users to prevent debt accumulation while disconnected.

Technical Decisions: Why this stack?

Docker & Infrastructure

Managed 6 distinct runtimes with isolated static networking (172.20.0.0/16). Used a read-only Docker Proxy to monitor metrics while maintaining a strict security boundary.

MERN + Socket.io

MongoDB's schema-less nature handled evolving subscriber states (SOS Access, Reactivate grants) without migrations. Socket.io provided the real-time backbone for technical support and kiosk control.

AI-Driven Workflow

Leveraged AI for edge-case diagnostics in the billing ledger and automated regression testing. I defined the business rules and network architecture; AI assisted in implementing complex state-machine interactions.

Side Project · Systems / Security

SafePlay

Anti-Cheat Tool for Online Games

GitHub ↗

A side project exploring how anti-cheat tools work. It's a Windows DLL for Ragnarok Online clients that serves a trusted configuration from memory, verifies game files, and checks for known cheat tools — paired with a launcher that makes sure the game starts clean. Written in C++ with AI assistance.

🔒 Configuration

Keeps game server settings stored safely in the DLL so they can't be easily changed.

✅ File Check

Verifies game files haven't been tampered with before allowing the game to start.

🪝 File Patching

Intercepts file access attempts to protect configuration from being modified.

🛰️ Cheat Detection

Regularly checks for known cheat tools running in the background.

🚀 Protected Launch

Game only runs through a special launcher to ensure protections are in place.

💬 Notifications

Shows the player what's blocking them if a cheat tool is detected.
